# Baibhav Collections — Shipping & Delivery Policy Page

This repository contains the bespoke **Shipping & Delivery Policy** website page designed for **Baibhav Collections**, referencing the functional structure of [Juxar](https://www.juxar.com/pages/shipping-and-delivery-policy) while implementing a unique visual identity, bespoke color scheme, and an interactive UI.

---

## 🎨 Design & Colour Scheme Comparison

| Feature | Reference Site (Juxar) | Baibhav Collections (New Design) |
| :--- | :--- | :--- |
| **Aesthetic** | Generic, plain minimal black & tan | **Royal Luxury, Artisanal & Contemporary Elegance** |
| **Primary Color** | `#222222` (Standard Black) | **Deep Royal Emerald (`#0f3d34`)** |
| **Accent Color** | `#b59677` (Muted Sand) | **Artisan Champagne Gold (`#c29d59`)** |
| **Background** | Flat pure white (`#ffffff`) | **Soft Warm Alabaster / Ivory (`#faf8f5`)** |
| **Typography** | Generic Sans-serif | **Playfair Display (Headings) + Plus Jakarta Sans (Body)** |
| **PIN Code Check** | Passive text instruction | **Interactive PIN Code Serviceability Tool with real-time feedback** |
| **Timeline** | Single sentence | **4-Step Visual Process Infographic & Regional Transit Matrix** |
| **Payment Breakdown**| Small plain note | **Side-by-side Prepaid vs COD Comparison Cards with Perks** |
| **Navigation** | Basic single-column text block | **Sticky Sidebar Table of Contents with ScrollSpy & FAQ Accordions** |

## 🚀 Key Features

1. **Interactive PIN Code Checker:** Allows customers to test their 6-digit Indian PIN code to view delivery serviceability and estimated days.
2. **Prepaid vs. COD Advantage Cards:** Highlights the **5% Extra Prepaid Discount** and transparent **₹49 COD handling charge**.
3. **Regional Transit Schedule:** Clear breakdown for Tier-1 Metros (2–4 days), Tier-2/State Capitals (3–5 days), and Rest of India (4–7 days).
4. **Logistics Partner Verification:** Badges for Blue Dart, Delhivery, DTDC, Xpressbees, Shadowfax, and India Post.
5. **Interactive FAQ Accordion:** Clean animated expand/collapse for common delivery concerns.
6. **Support Concierge Banner:** One-click Email and WhatsApp buttons.
